RustBB pkg repository

The rustbb package for FreeBSD 14 and 15, amd64 and arm64, signed by the RSA key rustbb.pub, whose SHA-256 is ff1acecac4db6aa020212bb93e3b540fe52b4a12bd6cb5ead18854375004b567 (sha256 /usr/local/etc/pkg/keys/rustbb.pub after fetching it). As root, to add it and install RustBB:

mkdir -p /usr/local/etc/pkg/keys /usr/local/etc/pkg/repos
fetch -o /usr/local/etc/pkg/keys/rustbb.pub https://rustbb.github.io/pkg/rustbb.pub
printf 'rustbb: {\n  url: "https://rustbb.github.io/pkg/${ABI}",\n  signature_type: "pubkey",\n  pubkey: "/usr/local/etc/pkg/keys/rustbb.pub",\n  enabled: yes\n}\n' \
  > /usr/local/etc/pkg/repos/rustbb.conf
pkg update -r rustbb && pkg install -y -r rustbb rustbb

Then set up the forum in /usr/local/etc/rustbb/env and run sysrc rustbb_enable=YES && service rustbb start. Upgrades come with pkg upgrade; a running forum goes on until service rustbb restart, which starts the new version. Deployment says what the package sets up.
